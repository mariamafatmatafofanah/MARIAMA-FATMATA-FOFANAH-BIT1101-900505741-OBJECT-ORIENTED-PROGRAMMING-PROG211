# Patient Record System

## Intrhealth_system.pyient Record System is a simple Python program developed using Object-Oriented Programming (OOP) to manage basic patient information and health records.

## Objectives
- Demonstrate OOP concepts in Python.
- Create and manage patient records.
- Demonstrate interaction between objects.
- Store multiple patient objects using a list.

## Features
- Create patient records.
- Display patient information.
- Update a patient's medical condition.
- Create health records.
- Check whether a patient is an adult.

## OOP Concepts Used
- Classes and objects
- Attributes
- Instance methods
- Class methods
- Static methods
- Object interaction

## Classes
### Patient
Stores the patient's ID, name, age, gender, and medical condition.

### HealthRecord
Stores the health record ID, patient, doctor, and treatment.
